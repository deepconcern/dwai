# Glossary

| Term | Meaning |
| ---- | ------- |
| **Advanced move** | A class move chosen on level up, from the 2–5 or 6–10 list. May require or replace another move. |
| **Alignment** | A class-specific ethos. Fulfilling it once per session is 1 XP. |
| **Armor** | Reduces incoming damage. Ignored by piercing. |
| **Basic move** | A move every character has (Hack and Slash, Defy Danger, ...). |
| **Bond** | A sentence linking your character to another party member. Campaign-scoped. |
| **Cantrip / Rote** | Wizard / Cleric spells that are always prepared. |
| **Class move** | A race, starting, or advanced move belonging to one class. |
| **Damage die** | The die a class rolls for damage (d4–d10). |
| **Danger** | A threat within a front, with an impulse and grim portents. |
| **Debility** | Weak, Shaky, Sick, Stunned, Confused, Scarred: −1 to one stat. |
| **Forward / Ongoing** | A bonus to the next roll / to rolls until a condition ends. |
| **Front** | GM prep grouping related dangers, with stakes and an impending doom. |
| **GM move** | What the GM does on a miss, when looked to, or on a golden opportunity. The GM never rolls. |
| **Grim portent** | One step of a danger's advance toward its impending doom. |
| **Hold** | A resource from a roll, spent on a move's options. |
| **Impending doom** | What happens if a danger's grim portents all come to pass. |
| **Load** | Carrying capacity: class base + STR modifier. |
| **Miss** | A roll of 6 or less. Mark XP; the GM makes a move. |
| **Move** | A rule triggered by the fiction ("When you…"). |
| **Move creation option** | (App term) A choice a starting move requires at character creation. |
| **Partial success** | A roll of 7–9. |
| **Piercing X** | Ignores X points of armor. |
| **Race move** | The class move chosen for the character's race at creation. |
| **Special move** | A move everyone has, used in particular situations (Last Breath, Make Camp, ...). |
| **Starting gear** | A class's default items plus pick-N option groups chosen at creation. |
| **Tag** | A keyword on an item or monster with a rules meaning (close, messy, 2 weight, solitary, ...). |
| **XP** | Experience. Level up at level + 7. |
