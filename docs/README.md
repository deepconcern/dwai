# Documentation

Agent-agnostic documentation for Dungeon World AI. Every agent (Claude Code, Copilot, or any other) and every human reads the same files. The entry point for agents is the root [`AGENTS.md`](../AGENTS.md).

| Section | Read it when |
| ------- | ------------ |
| [game/](game/README.md) | You touch anything that represents Dungeon World rules: API resolvers and validation, the character sheet, game data YAML, AI prompts |
| [app/](app/README.md) | You need the product vision, the architecture, how game concepts map to code, or the plan for the AI features |
| [workflow/](workflow/README.md) | You start any feature, enhancement, or fix, or you're asked to review a PR |

Also see [`ROADMAP.md`](../ROADMAP.md) for milestones and current status.
