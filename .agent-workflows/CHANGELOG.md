# Changelog

## v1.0.0

First release, extracted from the workflow used to build a hobby project with Claude Code and GitHub Copilot.

- Principles, the feature delivery workflow, and the junior engineer and reviewer roles.
- Skills: `gather-requirements`, `write-spec`, `implement-spec`, `write-tests`, `review-pr`.
- Stacks: React, Go + GraphQL, cloud agent sessions.
- Templates: project `AGENTS.md`, spec issue, PR body.
- `install.sh` to copy a tagged version into a project.
